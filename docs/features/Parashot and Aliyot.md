# פרשיות ועליות

← חזרה ל-[[index]]

מיפוי הקטע שמתאמנים עליו ב-[[docs/screens/First Window]].

## מה נעול

- מחזור **שנתי** — 54 פרשיות + 7 פרשיות כפולות (שבת שמחברים שתיים)
- לכל פרשה: **ראשון … שביעי + מפטיר**
- גבולות הפסוקים: טבלת `fullkriyah` מ-**Hebcal leyning** (`@hebcal/leyning`, BSD-2-Clause)
- קובץ הנתונים באפליקציה: `assets/data/parashot.json`
- הבחירה (ספר / פרשה / עלייה) **נשמרת** עד שהמשתמש מחליף — לא לפי לוח השנה, אלא לפי מה שבחר

## איך בוחרים

לא שלושה מסכים נפרדים. בחלון הראשי נפתח **חלון בחירה** שתופס כמעט את כל המסך. ראה [[docs/screens/First Window]].

סדר:

1. **ספר** (חומש)
2. **פרשה** — רק הפרשיות של הספר שנבחר (כולל הכפולה של אותו חומש, אחרי הפרשה השנייה בזוג)
3. **עלייה** — ראשון, שני, שלישי, רביעי, חמישי, שישי, שביעי, מפטיר

## פרשיות כפולות

מופיעות כפריט נוסף באותו חומש, אחרי הפרשה השנייה:

| כפולה | חומש |
|---|---|
| ויקהל-פקודי | שמות |
| תזריע-מצורע | ויקרא |
| אחרי מות-קדושים | ויקרא |
| בהר-בחוקתי | ויקרא |
| חוקת-בלק | במדבר |
| מטות-מסעי | במדבר |
| ניצבים-וילך | דברים |

גבולות העליות בכפולה הם של **שבת מחוברת** (7 עליות על שתי הפרשיות), לא חיבור של שני תיקונים נפרדים.

## ברירת מחדל

אם אין בחירה שמורה: **בראשית / בראשית / ראשון**.

## מה לא כאן

- עליות של שני-חמישי (weekday) — לא בשימוש
- הפטרה — לא בשימוש
- בחירה אוטומטית לפי שבת זו — רק אם ייכנס להגדרות אחר כך
