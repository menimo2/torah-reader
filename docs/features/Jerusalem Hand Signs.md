## אילו סימנים מוצגים במסמיך

לכל טעם יש `shownByDefault`. במסמיך מציגים את הסימן **רק** לטעמים שדלוקים. הצביעה ממשיכה לכל המילים.
`colorMs` של הטעם המוצג = כמה זמן הסימן נשאר בפס, גם אם הצביעה כבר התקדמה.

פעם ראשונה — הרשימה שביקש המשתמש:

זרקא · סגול · פזר · קרני פרה (פזר גדול) · תלשא · תילשא · אזלא גרש · פסק · רביע · שני גרשין · דרגא · תביר · אתנח · אזלא (תרי קדמין) · זקף קטן · זקף גדול · סוף פסוק

**מיפוי שמות:** «פזר-גדול» = `פזר` + `קרני פרה`. «תרי קדמין» = `אזלא` (קדמא). «תלשא» = תלישא גדולה, «תלישא» = תלישא קטנה. «אזלא גריש» = גרש וגם גרש מוקדם. «פסק» = הקו האנכי ב-WLC (`x-paseq`), נצמד למילה שלפניו. «זרקא» ב-WLC של 21 הספרים = U+05AE בסוף המילה (וגם U+0598 באמצע מילה). SBL Hebrew מציג את U+05AE; לא ממירים לגליף אחר.

השאר כבויים (טרחא, פשטא, שלשלת, יתיב, שופר הולך, שופר מהופך, מאריך, תרי טעמי, ירח בן יומו).

כיבוי/הדלקה לכל טעם — ב-[[docs/screens/Settings]]. הבחירה נשמרת עד שמחליפים.

## איך שולחים קבצים לערכה 3

תיקייה: `assets/signs/jerusalem/`

שולחים **תמונה או וידאו גולמי** של היד. לא שמים את הקובץ הגולמי במסמיך כמו שהוא.

ממנו מכינים תמונה/GIF בעיצוב אחיד: ריבוע 1024, רקע קרם (`#FAF7F0`), היד חתוכה צמוד (~6% שוליים) כדי שתהיה ברורה בפס. כל הסימנים ייראו מאותה משפחה.

שם הקובץ המוכן = ה-`id` מהטבלה למטה.

| סוג | קובץ מוכן | מתי |
|---|---|---|
| תמונה סטטית | `{id}.png` | תנועה שאפשר לראות בפריים אחד |
| GIF | `{id}.gif` | תנועה שצריך לראות בלופ **או** פעם אחת (לפי הטעם) |

ב-Chrome, `Image.asset` מציג רק את הפריים הראשון של GIF. לכן GIF בערכה 3 רץ כ-`<img>` של הדפדפן.

עד שיש קובץ מוכן לטעם — מוצגת היד ב-`default.png`.

## סגנון אחיד לערכה 3 (נעול)

כל הידיים חייבות להיראות מאותה משפחה — כמו `tevir.gif` / `zarqa.gif` / `azla.gif`:

| כלל | פירוט |
|---|---|
| גוון עור | עור אנושי בהיר־חמים (אפרסק / peach). **לא** צהוב אימוג'י ברירת מחדל |
| סגנון | אימוג'י / cartoon נקי, הצללות רכות, בלי קווי מתאר שחורים חזקים |
| יד | יד ימין, ירושלמי |
| רקע מוכן | קרם `#FAF7F0` (ריבוע 1024, ~6% שוליים) |
| משפחה | אותן פרופורציות והצללה — לא מערבבים צהוב עם אפרסק |
| שני גרשין | **גב היד** בלבד: מפרקים וציפורניים לכיוון המצלמה; ביד ימין האגודל בצד **ימין** של התמונה (אגודל משמאל = כף היד מלפנים — טעות). שתי אצבעות למעלה **צמודות**, אגודל מקופל |

אם מגיעה תמונה צהובה — ממירים לאפרסק לפני שמכניסים לערכה (או מייצרים מחדש לפי רפרנס).

### GIF — מה למדנו

- שם הקובץ = `id` (למשל `tevir.gif`)
- משך האנימציה: עדיף **פחות משנייה** כשהסימן נשאר ~1100ms בפס
- **לופ או פעם אחת:** בלי בלוק `NETSCAPE2.0` → רץ **פעם אחת** ונעצר. עם Netscape loop=0 → חוזר בלי סוף. תביר = פעם אחת
- תנועה קשיחה: כשמזיזים את כל היד כיחידה אחת — האצבע **לא** מתכופפת לבד
- קו נגרר: אם מציירים קו אחרי קצה האצבע — צבע אפור כהה דק, לא משנים את עיצוב היד
- כלי פנימי ליצירת GIF מתמונת יד: `tools/MakeQuarterArcGif.cs` (למשל קשת לרביע־תביר)

רפרנס צבע/עיצוב טוב: פריים מ־`tevir.gif` או `zarqa.gif`.
