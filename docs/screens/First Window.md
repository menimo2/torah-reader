| מקום | מה |
|---|---|

## בחירת ספר / פרשה / עלייה

לוחצים על הכפתור באמצע (מציג למשל «בראשית · ראשון»). נפתח חלון בחירה שתופס **כמעט את כל** המסך.

בסדר:

1. **ספר** — חמשת החומשים
2. **פרשה** — רק פרשיות הספר שנבחר, כולל פרשה כפולה אם יש בחומש הזה
3. **עלייה** — ראשון, שני, שלישי, רביעי, חמישי, שישי, שביעי, מפטיר

אחרי הבחירה חוזרים לחלון הראשי (עדיין בלי טקסט). הקריאה מתחילה רק בלחיצה על **אימון קריאה** או **מסמיך**.

ברירת מחדל בפעם הראשונה: בראשית / בראשית / ראשון.

## הגדרות

איקון למעלה משמאל → [[docs/screens/Settings]].

שם בוחרים את ערכת הסימן של המסמיך (א + טעם / שם / תמונות), רואים את הסט המלא, ומעלים תמונות אם רוצים.
הבחירה נשמרת עד שמחליפים. **שחזור הגדרות** מחזיר לברירת המחדל.

המסך עצמו — רשימת כל הטעמים בשלוש הערכות + זמן, מתג הצגה במסמיך, החלפת תמונה. דלוקים למעלה בכל פתיחה.
