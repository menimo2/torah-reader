# בעל קורא (torah-reader)

אפליקציית Flutter לתרגול קריאה בתורה. המפרט המלא ב-[index.md](index.md).

## הרצה

```bash
flutter pub get
flutter test
flutter run -d windows
```

בפתיחה הראשונה הטקסט מפורסר מ-XML ונשמר ב-SQLite.

## מקורות

- טקסט: [Open Scriptures Hebrew Bible](https://github.com/openscriptures/morphhb) (CC BY 4.0)
- גופן: Ezra SIL (`assets/fonts/SILEOT.ttf`, OFL)
